# keirin-lab（競輪3連単ラボ）

競輪の3連単を予想し、結果と照合して学習するスマホ向けのWebアプリです。（開発中）

## このアプリが使う情報
- 利用者が貼り付けた、チャリロトの出走表と3連単オッズ
- 利用者が貼り付けた、KEIRIN.JPの結果（照合と学習にだけ使用）
- 照合済みレースから積み上げた蓄積データ
- 開発時に調べて固定した参照データ（バンク諸元など。出典つき）

## 守っているルール
- レースの結果を先に見て予想することは一切しません。
- 運用中にWeb検索やサイトの閲覧はしません。
- 他サイトの予想印は予想に使いません。
