# keirin-lab（競輪3連単ラボ）

競輪の3連単を予想し、結果と照合して学習するスマホ向けのWebアプリです。（開発中）

## このアプリが使う情報
- 利用者が貼り付けた、チャリロトの出走表と3連単オッズ
- 利用者が貼り付けた、KEIRIN.JPの結果（照合と学習にだけ使用）
- 照合済みレースから積み上げた蓄積データ
- 開発時に調べて固定した参照データ（バンク諸元など。出典つき）

## 守っているルール
- レースの結果を先に見て予想することは一切しません。
- 運用中にWeb検索やサイトの閲覧はしません。例外は天気だけで、気象データ（[Open-Meteo](https://open-meteo.com)）から、開催日・競輪場のおおよその位置・発走時刻（分からなければ時間帯から見積もり）の天気と風を取ります。風向きは競輪場ごとのバンクの向き（`refdata.js` の `homeHead`）で「ホーム向かい風」などに直します。ほかのサイトの予想・オッズ・結果は見ません。
- 他サイトの予想印は予想に使いません。

## 注意
- 的中を保証するものではありません。回収率は100%を下回るのが普通です。
- 車券の購入は20歳になってから。無理のない範囲でお楽しみください。
